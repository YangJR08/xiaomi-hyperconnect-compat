# Repository agent instructions

For any request to install Xiaomi PC Manager or Super XiaoAI, bypass an
unsupported-device check, generate a model-specific compatibility DLL, build
the `msimg32` proxy, validate an installation, or roll back changes, read
`skills/install-xiaomi-hyperconnect/SKILL.md` completely before acting.

Follow the Skill's hash, version, signature, backup, UAC, and rollback rules.
Use Xiaomi's official download page and the bundled scripts. Do not download
installers from mirrors, write to `C:\Windows`, force the legacy
`XiaoaiHost.dll` onto another version, or overwrite an unknown same-name file.
